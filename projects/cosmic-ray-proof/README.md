# Cosmic-ray proof pair

First production packet for the illustrated GOLIDE explainer format.

## Approved direction

- No generic AI-cinematic footage.
- Original ink-and-paper scientific illustration language.
- Visual change every 2–4 seconds in Shorts and 5–8 seconds in 16:9.
- One research packet supports two independently written videos.
- Claim-level evidence, rights-safe assets, and human QA before publishing.

## Working package

| Output | Short | Long |
|---|---|---|
| Title | A Particle From Space Can Flip a Computer Bit | How Space Can Flip a Bit Inside Your Computer |
| Duration | 55–65 seconds | 4:15–4:50 |
| Aspect ratio | 9:16 | 16:9 |
| Visuals | 21 flips from 10 base illustrations | 43 flips from 16 base illustrations |
| Spoken pace | 165–175 WPM | 145–155 WPM |

Production is intentionally blocked until the source packet and script are approved.

## Visual proofs

- `assets/style/golide-style-frame-v1.png` — four-panel look and visual-flow test.
- `assets/thumbnail/thumbnail-concept-v1.png` — first no-text thumbnail direction.

Both are design proofs, not final scenes. Final artwork will reuse the same palette,
line character, and causal clarity while keeping individual frames independently
