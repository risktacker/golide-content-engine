# Thumbnail styles (trial 2026-11-10)

Six editing styles modelled on the owner's references: light glass, platter row, dark drama, editorial type,
grid paper + script, real object + highlight. 3D glossy logo tiles render in Three.js (icons.html via icons.js);
make.py composes backgrounds and type (Anton, Archivo Black, Poppins, DM Serif Display: OFL, from @fontsource).
Not wired into the engine until the owner approves.
